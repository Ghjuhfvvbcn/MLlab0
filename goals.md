# Мой опыт
Мой скромный опыт написания программ. Программы на Python для ЕГЭ по информатике. Программы на Arduino C для модели машинки, управляемой Arduino. Она могла управляться с пульта от телевизора, или кататься самостоятельно определяя расстояние до препятствий с помощью УЗ-датчика расстояния. Выполнение лабораторных работ по Java и использования Python для различных учебных задач, таких как построение графиков, моделирование систем диф. уравнений и пр. Еще однажды я навайбкодил программу-таймер, в котором на звонок можно поставить любой mp3-файл, хотя это не разработка ПО. Прочитать интересную статью на википедии, никак не связанную с темой лабораторной работы, можно по [ссылке](https://ru.wikipedia.org/wiki/Королёв,_Сергей_Павлович).
# Мои цели
1. Разобраться, в чем разница между Машинным обучением и Искуственным интеллектом
2. Использовать знания, полученные на курсе, для создания каких-нибудь прикольных штук. Пока, правда, не знаю, каких именно.
3. Сдать экзамен на 5.

## Задачи
- Посещение лекций и выполнение лабораторных работ, со стремлением к пониманию происходящего.
- Еженедельный просмотр мемов по предемту.
- Применение полученных знаний для внеучебных задач.
